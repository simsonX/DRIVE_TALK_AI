# 시연 준비와 순서

## 준비

1. 일반 Android 에뮬레이터를 켜고 앱 APK를 설치한다.
2. 영어/한국어 Android TTS 음성 데이터와 미디어 볼륨을 확인한다.
3. 로컬 Ollama 및 `python3 ai-server/server.py`를 실행한다.
4. `python3 scripts/verify_qwen.py`로 실제 모델 응답을 확인한다.
5. 앱에서 설정 → **DEMO 주차**를 선택한다. 상단 DEMO 표시를 확인한다. 실제 주차 신호를 수신한 것이 아니다.

## A. 출근길 청취

설정에서 비즈니스/초급/5개 문장을 고르고 오늘의 학습 → 출근길 학습 시작.

기본 예문: “I have a meeting today.” / “오늘 회의가 있어요.”

영어→2초 쉬기→한국어→2초 쉬기→영어 순서로 천천히 청취한다. 다음 문장 전에는 기본 8초(설정에서 5·8·12초 선택)의 따라 말할 시간을 준다. 선택 개수를 마치면 자동 종료하며, 콘텐츠가 부족하면 준비된 서로 다른 문장 수만큼 진행한다. 반복은 개수를 중복 집계하지 않고 건너뛴 문장은 완전 청취로 기록하지 않는다. 반복/다음/일시정지/재개/종료를 확인한다. 음성 명령 버튼은 마이크 권한을 요청하며 실제 Android STT에 “반복”, “다음”, “일시정지”, “재개”, “종료”를 말할 수 있다. 상시 듣기/핸즈프리 웨이크워드/Gleo는 미구현이다.

완전 청취 후 기록의 청취 횟수는 늘고 정답 횟수는 늘지 않는다. 세션 시간도 저장된다. DEMO 주행으로 변경하면 문장·퀴즈·상세 학습 UI가 숨겨진다.

## B. 어려운 표현과 퇴근 복습

DEMO 주차에서 현재 문장을 “어려워요”로 평가한다. 학습 기록에서 어려움 표시와 다음 복습 일자를 확인한다. “다시 학습”은 오답+1/10분 후, “알겠어요”는 정답+1/1일 후부터 간격이 늘어난다.

퇴근길 복습을 시작한다. 같은 카테고리·수준에서 어려운 표현이 앞에 오는지 확인한다. 기록이 없으면 빈 상태 안내가 나와야 한다.

앱 프로세스를 종료 후 다시 열어 기록 유지와 차량 상태 UNKNOWN 복귀를 확인한다. 다시 DEMO 주차를 선택해야 상세 기록이 열린다.

## C. 실제 Qwen 예문

주차 상태에서 Qwen 예문 생성을 누른다. “Qwen 실제 생성 · 언어 정확성 미검수” 출처와 생성 문장을 확인한다. 문장을 확인한 뒤 문장 들어보기를 누르면 영어/한국어 음성으로 출력된다.

생성이 끝나면 **다른 예문 생성** 버튼을 다시 눌러 새 문장을 만든다. 최근 문장 6개와 동일한 문장은 거부하고 생성 완료 횟수를 표시한다. 생성 실패/시간 초과 후에도 현재 문장을 유지하며 재시도할 수 있다.

설정에서 중급으로 바꾸고 같은 주제의 예문을 다시 생성한다. 초급과 중급의 실제 모델 결과는 `qwen-evidence.json`에 별도 보관한다. 모델이 부정확한 설명을 만들 수 있으므로 교사의 확정 판정으로 사용하지 않는다.

## D. 주차 회화

AI 영어회화 → 새 회화 시작. 실제 Qwen 질문을 듣는다. 마이크로 답변 또는 주차 중 텍스트 답변을 사용한다. 두 입력 경로는 화면에 구분해 표시한다.

테스트 문장: “I go to work yesterday.”

교정된 영어와 설명을 확인한다. AI는 자동 점수를 주지 않는다. 다음 질문을 눌러 최대 5턴까지 진행한다. 교정 표현을 어려움으로 저장하면 이후 같은 카테고리/수준의 복습에 포함된다.

실제 사람이 마이크로 답한 경로와 텍스트로 입력한 경로는 서로 다른 검증이다. 자동화에서 텍스트를 사용한 결과를 실제 발화 인식 성공으로 보고하지 않는다.

회화 처리 중 DEMO 주행으로 바꾸면 회화 화면·음성·응답 반영이 중단되어야 한다.

## 오류와 대체 시연

| 상황 | 동작/시연 |
|---|---|
| AI 서버 종료/모델 없음 | 기본 54개 문장 학습 유지. 현재 문장을 유지하고 생성 재시도 가능. 회화는 실제 오류 표시 |
| 잘못된 JSON/한국어 누락 | 서버 검증이 거부하고 제한된 재시도 후 오류. 고정 응답을 Qwen이라고 표시하지 않음 |
| TTS 음성 데이터 없음 | 해당 언어 설치 안내. 성공한 척 재생하지 않음 |
| STT 없음/권한 거부/인식 실패 | 오류 안내. 주차 중 텍스트 답변으로 대체하되 출처 표시 |
| 네트워크 없음 | 로컬 기본 콘텐츠와 설치된 온디바이스 TTS 사용. Android STT/일부 TTS 엔진은 별도 의존성 있음 |
| 차량 상태 접근 불가 | UNKNOWN으로 주차 기능 제한. 일반 Android debug DEMO만 수동 전환 가능 |
| 내비/전화 오디오 포커스 손실 | Media3가 일시정지/중단. 내비 transient 종료 후 적절히 복귀, 영구 손실 후 사용자 재개 |
| 기록 없음 | 퇴근 복습 빈 상태 안내, 출근 학습 제안 |
| 앱 재시작 | Room 기록 복구, 재생/DEMO 주차 자동 복구하지 않음 |

앱은 사용자의 시간 설정만으로 운전·출퇴근 여부를 판단하거나 오디오를 자동 시작하지 않는다. 실제 Pleos 서비스 없는 환경에서 차량 연동이 완료되었다고 설명하지 않는다.
